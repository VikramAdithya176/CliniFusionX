# Training Scripts

These scripts are **offline training utilities** and are **not part of the runtime inference pipeline**.
They were used to build and fine-tune the multimodal CliniFusion model.

## Scripts

| Script | Purpose |
|---|---|
| `generate_synthetic_symptoms.py` | Reads NIH ChestX-ray14 labels CSV and generates a synthetic symptom vector per patient using CCM rules |
| `train_fusion.py` | Fine-tunes the `CliniFusionNet` (Swin backbone + GatedFusion layer) on NIH ChestX-ray14 with synthetic clinical symptoms |
| `gated_fusion.py` | GatedFusion module definition — fuses Swin image features with clinical/symptom vectors |

## Prerequisites

```
nih_with_symptoms.csv       ← generated by generate_synthetic_symptoms.py
images/                     ← NIH ChestX-ray14 image folder
best_swin_chestxray14.pth   ← pretrained Swin weights (root of project)
```

## Usage

```bash
# Step 1 — generate symptom vectors from NIH label CSV
python scripts/generate_synthetic_symptoms.py

# Step 2 — fine-tune the fusion model
python scripts/train_fusion.py
```
